# OpenCode — независимая проверка A

Проверь нативный Android-порт NeDotify. Исходники находятся в родительской папке
этого файла (`android/`), требования — в README.md и PORTING_STATUS.md,
визуальный референс — design/reference.png. Проверяемая версия зафиксирована
контрольными суммами SOURCE_SHA256.txt. Сначала проверь соответствие сумм.

Работай только на чтение исходников. Допустимы compile/unit/lint в build/.
APK сейчас собирать запрещено: не запускай assemble/package APK. Старый 0.2.0
не содержит текущие исходники и не подтверждает их runtime-поведение.
Не запускай других агентов. Не меняй desktop и ~/.nedotify. Не читай секреты.
Не используй выводы другого ревьюера. Самостоятельно проверь всю версию.

Основной акцент: MediaSessionService/MediaController, жизненный цикл, восстановление
очереди и позиции, быстрые смены треков, отмена запросов, single-flight, обновление
URL, progressive/HLS, Room-транзакции, измеренная история, разрешения и безопасность.
Особенно проверь два декодера/передачу делегата MediaSession, единый AudioFocus,
отмену crossfade и recovery, очистку/перестановку очереди, smart reactive SQL,
миграции v1→v2→v3, desktop READONLY import, OAuth/Keystore/PKCE/401/отмену и
утечку токена через redirect/CDN, ограниченность ответов и JSON.
Проверь реальные ограничения SoundCloud/YouTube: успешный поиск не означает поток.
Отдельно проверь поведение минимального API 26 и API 37.

Запусти unit/lint/compile Android tests по README.md без APK.
Если устройство недоступно — явно раздели статический анализ и проверенные сценарии.
Не устанавливай драйверы, не перезагружай систему, не публикуй APK.

Для каждого дефекта укажи серьёзность (P0/P1/P2/P3), файл:строку, воспроизводимый
сценарий, последствие и конкретное исправление. Отдели текущие дефекты первого этапа
от функций следующих этапов, уже явно помеченных нереализованными в PORTING_STATUS.
Верни фактические команды и результаты, контрольную сумму SOURCE_SHA256.txt,
оставшиеся непроверенные сценарии. Не выдавай неподтверждённое предположение за баг.

Сохрани свой отчёт отдельно или передай пользователю. Не исправляй файлы автоматически.
