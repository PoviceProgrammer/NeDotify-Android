# OpenCode — независимая проверка B

Проверь нативный Android-порт NeDotify по README.md, PORTING_STATUS.md и
design/reference.png. Проверяемая версия исходников зафиксирована в
SOURCE_SHA256.txt. Сначала проверь соответствие сумм. Проверяй самостоятельно:
не читай отчёт другого ревьюера и не принимай выводы автора за доказательство.

Работай только на чтение исходников. Разрешены compile/unit/lint без APK.
Пользователь запретил новую сборку APK. Старый 0.2.0 не содержит текущий UI.
Не запускай других агентов, не меняй desktop или пользовательскую библиотеку.

Основной акцент: реальные пользовательские сценарии, Compose-состояние, навигация,
системный Back, insets, клавиатура, светлый/тёмный режимы, настоящий backdrop blur
и fallback, контраст, TalkBack, 48dp, большие шрифты, длинные названия, пустота,
загрузка, ошибки, отсутствие обложек и производительность. Проверь мини/полный
плеер, очередь, библиотеку, плейлисты, избранное и сохранение настроек.
Находи также функциональные ошибки за пределами основного акцента.

Не устанавливай старый APK для проверки нынешних изменений. Визуальный запуск и
снимки текущего кода пока недоступны. Выполни source-проверки по README.md.
Дополнительно проверь smart-rule dialog, auth/catalog, real Dynamic Color,
группы поиска/частичный успех, EQ capabilities и сохранение настроек.
Отдельно перечисли, что действительно
проверено в работающем приложении, а что оценено только по коду. Не подменяй
скриншотами референса снимки настоящего приложения. Не меняй системные драйверы.

Для каждого дефекта верни P0/P1/P2/P3, файл:строку, сценарий, последствие,
исправление. Не считай недостающие функции следующих этапов скрытыми дефектами,
если они явно отмечены в PORTING_STATUS; оцени честность этих ограничений.
Приложи команды, результаты, checksum SOURCE_SHA256.txt и список непроверенного.
Отчёт передай пользователю отдельно. Исходники автоматически не исправляй.
