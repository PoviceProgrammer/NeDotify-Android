# Приёмка Android после разрешённой свежей сборки

Статус: **не выполнена**. Компиляция instrumentation не равна этим проверкам.
Старый APK 0.2.0 не годится для приёмки нынешних исходников.
Использовать отдельный профиль Android и собственные тестовые файлы/аккаунты.

## Обязательные сценарии

1. Чистый запуск, существующий профиль Room v1/v2→v3; библиотека и история
   сохраняются. Старые/повреждённые DataStore значения не блокируют запуск.
2. SAF/MediaStore: разрешить/отклонить, выбрать файлы, теги/обложки,
   перезапуск с URI grant, переместить файл, повторно связать. Общее разрешение
   не требуется для SAF. Сканирование не удаляет пользовательские записи.
3. Local/SoundCloud progressive/VOD HLS: play/pause/seek/next/previous/repeat/
   shuffle, ошибка и один retry, истёкший URL, пауза во время retry.
   Проверить настоящий звук, а не только движение прогресса.
4. Очередь: выбрать/переместить/удалить текущий/следующий/последний трек,
   очистить во время подготовки, перезапустить, восстановить на паузе;
   shuffle traversal сохраняется, новые Flow-треки добавляются после него.
5. Crossfade 0/1/6/12 секунд: настоящий переход двух декодеров, короткий трек,
   repeat-one/all, shuffle, seek/смена очереди/ошибка в начале/конце fade,
   stalled incoming. После ручной паузы звук сам не возобновляется.
6. AudioFocus: другое музыкальное приложение/звонок, duck/transient/permanent,
   noisy при отключении проводных/BT наушников; поздний gain после паузы.
   Одна сессия/медиауведомление, управление гарнитурой/экраном блокировки.
7. EQ/бас/пространственный эффект: поддержка и отсутствие поддержки, смена
   audio session, настройка при crossfade, отсутствие clipping/утечки эффектов.
   Два быстрых переключения и две разные EQ-полосы сохраняются одновременно.
8. FGS: Home/блокировка/длительный фон/убийство Activity/процесса,
   повторный controller bind; чужой недоверенный controller отклоняется.
9. Flow: пустая/малая/большая коллекция, offline, autoplay у конца shuffled
   очереди, нет повторов текущей очереди, ошибочный источник не вызывает цикл.
10. Smart playlists: все фильтры, 0/1/много треков, обновить избранное/скачивание/
    историю/правила, переименование, удаление; broken rules→исправление.
11. Downloads: queued/preparing/downloading/paused/failed/complete/removing,
    отказ notifications, network loss/resume/process death, параллельный лимит,
    мало места, pause/remove/restart race. HLS/seek в airplane mode, без сети.
    Удаление offline сохраняет избранное/плейлисты.
    Создать очередь до завершения загрузок, дождаться их завершения, включить
    offline на локальном/удалённом треке: следующие скачанные элементы играют.
12. JSON v1/v2 и desktop DB: preview/cancel/merge, повтор, конфликт/повреждение/
    oversized/нестандартная схема. Исходная DB побайтово не меняется, история
    не удваивается, Windows-путь не становится доступным Android-файлом.
13. Spotify: реальный собственный Client ID/redirect, cancel/state/срок/replay,
    холодный запуск callback/rotation, refresh/401/logout; tokens не в логах.
    Проверить ограничения доступа API аккаунта, metadata≠playable preview.
14. Яндекс: собственный OAuth, отказ/отзыв/401, каталог/плейлисты/полный трек,
    права аккаунта. В redirect/CDN не утекает токен.
15. Keystore: перезапуск/процесс, повреждённая запись/alias, повторный вход.
    Токены не попадают в JSON и системный backup.
    Выход/смена аккаунта во время HTTP 200/401 и пагинации не возвращает прежние
    данные; новый аккаунт не использует подписанные URL прежнего аккаунта.
16. Поиск: debounce/IME/история, источники и «Все», partial success,
    пустота/ошибка/повтор, реальные artist/album groups и запуск их очереди.
17. Lyrics: все источники, правильная версия/исполнитель/длительность, synced/
    plain/instrumental/not-found/error/retry; ручной scroll/return/seek,
    кэш offline после процесса, предыдущий трек не оставляет текст.
18. Reports: wall-clock без seek inflation и double counting crossfade,
    пауза/повтор/полночь/DST, 7/30/all и сравнение, отсутствующий трек истории.
    Повторная привязка файла и смена stream→offline того же трека сохраняет
    одну сессию; явный replay создаёт следующую.
19. UI по design/reference.png: 320/360/411dp, планшет/landscape/разделённый экран,
    клавиатура, insets, 200% шрифт/TalkBack/RTL, длинные имена/нет обложки,
    пустота/загрузка/ошибка; все меню и диалоги достижимы.
20. Light/dark/system, 4 акцента+Dynamic Color, фон/glass/power saver/API26–30
    fallback, animation scale=0. Проверить переключение на играющем треке.
    Отдельно проверить первый кадр светлой темы.

## Свидетельства

Зафиксировать версию Android/модель/API, хэш нового APK и source manifest,
результат каждого пункта, logcat без секретов, screenshots home/search/library/
settings/profile/player в light/dark и узком/широком окне.
Независимые ревью должны ссылаться на текущий SOURCE_SHA256, а не старый baseline.
